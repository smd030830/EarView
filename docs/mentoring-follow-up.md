`ScoreCalibration.kt`에서 관리하며 보정치는 0이다. 보정 점수를 모델별로
0~1로 제한한 다음 같은 시점의 세 점수를 평균한다. 소리별 판정 기준값은
경적 0.3, 나머지 0.5로 유지했다.

## 진동 처리

위험도 순서는 기존 표시 순서(화재경보 → 사이렌 → 유리 깨짐 → 초인종 →
문 두드림 → 차량 경적)를 따른다. 재생 중인 패턴보다 우선순위가 높은 소리는
즉시 전환하고, 같은/낮은 소리는 기존 패턴을 유지한다. 억제한 진동을 나중에
재생하지 않아 종료된 사건이 뒤늦게 울리지 않도록 했다. 소리 이름은 기존처럼
화면에 최대 3개까지 표시한다. 종료·화면 탭 때 우선순위 상태도 초기화한다.

오디오는 수집하지 않고 외부 공개 평가 음원만 개발 PC에서 사용했다.
감지 기능에는 네트워크나 음원 저장 기능을 추가하지 않았다.
